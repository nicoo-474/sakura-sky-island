# 空の島 · Sakura Sky Island

一个纯程序化生成的「樱花空岛」3D 场景，单文件网页，用 Three.js 从零建模——没有任何外部模型、贴图或音效素材，所有几何体、贴图、云层、星空、月面都是在运行时算出来的。

> A procedurally generated floating sakura island, built entirely in code with Three.js. No external models, textures or audio assets — every mesh, texture, cloud, star and crater is generated at runtime.

---

## 场景内容

- **空岛**：非规则轮廓的径向网格地形 + 分层岩体，地表用 Canvas 现场绘制的「厚涂」贴图（同一樱花色系的六档纯色、三层笔触，并复用为 bumpMap 做出颜料堆叠感）
- **植被**：一簇六叶的自定义草簇几何（两万多个实例，顶点着色器风场）；单色小花；递归分叉的樱花树（枝干沿曲线收分，叶团用球面法线的贴图卡片）；垂枝樱；持续飘落的花瓣
- **和风建筑**：明神鸟居（注连绳 / 纸垂 / 神额 / 提灯 / 风铎 / 藤蔓）、妻入小祠（格栅门、翘角屋顶、注连绳）、石灯笼、参道石板、断柱倒梁等遗迹、崖边观景台
- **做旧**：木纹与石纹程序贴图 + 世界高度积垢着色器（墙脚越脏、带竖向水痕与霉斑）
- **副岛与魔法锁链**：四座小岛按 270° 均分环绕，每座都有樱树；锁链以双螺旋缠满主岛岩体，链节为实例化环形，链芯是带流动脉冲与符文带的加色管线，另有 460 颗沿链流动的火花
- **天空**：三层 fbm 流云、常驻闪烁星野、带环形山与月海的月球、从月面直射而下的体积光柱
- **昼夜**：黎明 / 晴日 / 黄昏 / 夜 四组预设，天空、雾、月、云、灯光整体插值过渡

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖拽 / 滚轮 | 环视 / 远近 |
| 時 | 黎明 · 晴日 · 黄昏 · 夜 |
| 風 | 风力，影响草、枝叶、花瓣、云的流速 |
| 音 | 背景音乐开关 + 音量，可点「選曲」载入本地音频 |
| 自動回旋 | 自动缓慢旋转镜头 |
| 花吹雪 | 花瓣数量拉满 |

## 运行

直接双击 `sakura-island.html` 即可（依赖同目录的 `libs/three.min.js`）。

或用任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/sakura-island.html
```

## 背景音乐

出于版权考虑，仓库**不包含**音乐文件。播放器会自动寻找同目录下的 `bgm.mp3`（也支持 `.ogg / .m4a / .wav / .flac`），把你有权使用的曲子放进去即可自动播放；也可以在页面里点「選曲」或直接把音频文件拖进画面。

## 构建

`build/` 下是拼接前的分段源码，按顺序合并即可还原：

```bash
cat build/head.html build/a.js build/b.js build/d.js build/c.js \
    build/f.js build/g.js build/e.js build/tail.html > sakura-island.html
```

| 文件 | 内容 |
| --- | --- |
| `head.html` | 页面骨架、UI、CSS |
| `a.js` | 工具函数、程序化贴图、天空/星/月、光照、风场注入 |
| `b.js` | 空岛地形与岩体 |
| `d.js` | 和风建筑、遗迹、做旧材质 |
| `c.js` | 草、花、樱树、落花 |
| `f.js` | 副岛与魔法锁链 |
| `g.js` | 背景音乐播放器 |
| `e.js` | 云、昼夜预设、交互、主循环 |

## 实现笔记

- **双面法线翻转**：`side: DoubleSide` 时 three 会按 `gl_FrontFacing` 翻转法线，草叶/花瓣这类薄片约半数会被翻成朝下而发黑；用 `onBeforeCompile` 把 `faceDirection` 固定为 `1.0` 解决。
- **体积光**：沿视线方向看圆柱时 `N·V → 0`，光柱会整个消失；因此光锥的衰减指数要按观察角度重新调（这里用 `pow(N·V, 0.85)` 保留软边）。
- **锁链贴合**：螺旋半径不能靠公式估算（会陷进岩体或浮空），改为把岩体顶点存下来，按「角度 ±0.14、高度 ±0.85」查局部最大半径再外扩。
- **音频探测**：首屏构建会长时间阻塞主线程，`<audio>` 的 `loadedmetadata` 事件会被挤掉，导致误判文件不存在；改成轮询 `readyState` 才稳定。
